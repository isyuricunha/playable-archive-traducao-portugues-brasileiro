# Glossário PT-BR

Decisões da tradução manual concluída em 26/10/2026. Aplicadas aos dois lotes de 250 e 226 entradas. Rever somente
com evidência contextual e manter as entradas relacionadas consistentes.

| Origem | PT-BR | Contexto |
| --- | --- | --- |
| Threshold | Limiar | Estrutura/limiar ritual, com inicial maiúscula |
| binding | aprisionamento | Processo ritual que sujeita a entidade |
| bind | aprisionar / prender / vincular | Verbo adaptado à frase, sem confundir com mãos atadas |
| keys of binding / bind keys | chaves de aprisionamento | Símbolos de comando, não chaves de portas |
| commencement keys | chaves de iniciação | Primeiro vínculo de serviço da entidade |
| Code keys | chaves de código | Informação obtida por símbolos/números |
| pediment | frontão | Estrutura triangular do ritual |
| pediment slate | placa do frontão | Peça/superfície do conjunto, não necessariamente pedra |
| slate of greeting | placa de saudação | Recepção da entidade e apresentação de oferenda |
| slate of command | placa de comando | Invocação do pacto |
| slate library | coleção de placas | Coleção do jogador |
| goetic geometry | geometria goética | Linguagem e desenhos dos compêndios |
| tracing | traçado | Forma desenhada ou ato de traçar |
| marking | marca | Símbolo/gravação, conforme contexto |
| edict markings | marcas de autoridade | Marcas que impõem serviço |
| offering | oferenda | Oferta ritual |
| incantation bowl | tigela de invocação | Recipiente para oferendas |
| intent | intenção | Efeito modificado pelas peças |
| tithe | dízimo | Expressão ocultista dos sussurros |
| Compendium | Compêndio | Livro/conjunto de conhecimentos |
| planchette | ponteiro de uma tábua ouija | Objeto usado para traçar, não a placa inteira |
| Rehoboam / Solomon / Abijam | Roboão / Salomão / Abias | Formas bíblicas em português |
| eidola | espectros | Entidades da carta de Henry |
| atrament | negrume | Imagem poética de escuridão na carta |
| mini DV | mini DV | Formato das fitas/câmera |
| closed captioning | legendas descritivas | Falas e indicações sonoras |
| sledgehammer / crowbar | marreta / pé de cabra | Ferramentas da reforma |
| hands bound | mãos atadas | Não usar aprisionamento no sentido de amarrar as mãos |

deliberadamente. Robbins/Robins mantém a divergência de cada fonte, sem alterar
